Local character images. Anything in here (except this file) is ignored by git.

- `node tools/fetch-images.js --download` saves every character's AniList image here.
- To use your own picture instead, save it as `<id>.jpg`, `.png` or `.webp` (ids are in `../js/characters.js`).
  A local file always wins over the URL in `js/images.js`.
